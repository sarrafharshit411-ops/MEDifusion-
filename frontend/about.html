Research Methodology & System Documentation

Architecture, datasets, model pathways, evaluation context and limitations of MediFusion AI.

Project overview

MediFusion AI is a web-based academic prototype that integrates radiology image classification, symptom-based prediction, structured clinical prediction, a 41-class general disease module and an experimental multimodal fusion pathway.

The application uses a FastAPI backend and a multi-page HTML, CSS and JavaScript frontend. PyTorch/ResNet-18 supports image classification; XGBoost supports structured prediction; Grad-CAM, SHAP and multimodal analysis utilities provide explanations where implemented.

Developer and repository contributor: Harshit Raj (S24CSEU0733).

Project status: Academic and research prototype only. It is not a clinically validated diagnostic device and must not be used for self-diagnosis or treatment decisions.

System architecture

The multimodal pathway combines a 512-dimensional image representation, a 15-dimensional symptom representation and a 22-dimensional clinical representation. Each stream is projected to a shared 128-dimensional space by the current GatedAttentionFusion source defaults.

  • Image stream: ResNet-18 feature extraction and image classification.
  • Symptom stream: binary symptom features for structured prediction.
  • Clinical stream: 15 symptom indicators plus seven physiological values.
  • Fusion: learnable per-modality gates, availability masking, multi-head attention and a four-class classifier.
  • Output: structured predictions, modality weights and explanation payloads where available.

The current source-code defaults are projection_dim=128 and num_heads=2 in src/models/fusion_model.py.

Datasets and validation boundaries

Chest X-ray and symptom datasets come from independent sources and are not linked by patient identifiers. Clinical physiological values for the fusion demonstration include synthetic data. Accordingly, the fusion pathway demonstrates architectural integration, not patient-level clinical validity.

Dataset references and their respective task details are recorded in data/README.md. Upstream dataset creators are acknowledged as data sources; they are not represented as project developers or contributors.

Explainability

Grad-CAM produces image activation heatmaps; SHAP attributes tabular model outputs to input features; modality ablation estimates changes in the winning-class score when a stream is removed; and cross-modal attention exposes a 3 × 3 attention matrix.

These visualisations describe aspects of model computation. They are not proof of pathology, causality or clinical diagnosis.
